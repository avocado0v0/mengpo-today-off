# 《孟婆今天請假》

一款以 Phaser 製作的桌面瀏覽器短篇管理喜劇。你是男性代班孟婆，每次隨機接待三位亡者，挑選孟婆湯、安排服務順序，並在三條同步下降的耐心條歸零前處理投訴。

## 本機遊玩

需要 Node.js 20.19 以上版本。

```powershell
npm install
npm run dev
```

終端機顯示本機網址後，在瀏覽器開啟該網址。點「開始代班」即可遊玩。

## 操作

- 滑鼠點擊介面按鈕。
- `Q`、`W`、`E` 選擇先接待哪位亡者。
- 數字鍵 `1`、`2`、`3` 選擇配方或回應。
- `Enter` 繼續劇情、教學與結果。
- `Esc` 將目前亡者放回待辦清單。
- 點右上角 `?` 三次可觸發陰間 AI 客服彩蛋；點湯杓 `♨` 五次可觸發隱藏結果。

## 發布

Vite 專案已設定 GitHub Pages 靜態建置流程。推送至 `main` 後，GitHub Actions 會建置並部署 `dist/`。
